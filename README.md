# Character iPhone — GitHub Pages starter

A single-file, iPhone-inspired interactive character phone prototype.

## Publish on GitHub Pages
1. Create a new public GitHub repository (for example `character-iphone`).
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then Save.
6. Wait for GitHub Pages to publish your `https://YOUR-USERNAME.github.io/character-iphone/` site.

## Current starter features
- Lock screen with live date/time and swipe/tap to reveal passcode.
- Demo passcode: `0215`.
- Incorrect passcode shake animation and simple synthesized key sounds.
- Home screen with tappable app icons.
- Contacts list with search and individual contact cards.
- Photos grid with sample abstract placeholder thumbnails.
- Messages with sample conversations and scripted character replies.
- Phone recents, and app screens for the other standard-style icons.
- Camera permission request using the browser camera API. Camera access requires HTTPS (GitHub Pages provides HTTPS) and the visitor's permission.

## Customize next
Edit the `contacts`, `threads`, and `scriptedReplies` arrays near the top of the script in `index.html`. Replace the abstract photo placeholders with your character's actual images in a later pass.

This is an original iPhone-inspired fan interface, not Apple's iOS and not affiliated with Apple. Browser/device behavior and sound availability vary. Sounds begin only after user interaction.
